# Guess Breakers website

A tiny, static four-page public website for the Guess Breakers YouTube channel: a homepage, a page of free printable activities for teachers and parents (`teachers.html`, PDFs and preview in `worksheets/`), a sources page (`sources.html`, generated from the episode descriptions by `tools/site/build_sources.py`; run it again after each new upload) and a privacy policy. It is intended for publication in the public GitHub repository `dimitar-radenkov/guess-breakers` and hosting at `https://dimitar-radenkov.github.io/guess-breakers/`.

The site uses only local HTML, CSS and image files. It has no forms, analytics, cookies, external scripts or external fonts. Outbound links are plain links to YouTube and Google policy/account pages.
